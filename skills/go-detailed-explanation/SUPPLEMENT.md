> 本文即该登记：**本技能不交付补充件**，理由如下。

## 1. 判定：不适用（已显式登记）

四件套（SKILL / BOUNDARIES / INDEX / GLOSSARY）已覆盖本技能的全部运行期需要：

| 需要 | 已由谁承载 |
|---|---|
| 判据与可执行流程 | `SKILL.md`（R/I/A1/A2/E/B ＋ 🔴CHECKPOINT ＋ 输出结构） |
| 边界与让位 | `BOUNDARIES.md` |
| 术语、页锚、池 id 索引 | `GLOSSARY.md` |
| 引用图与交叉引用约定 | `INDEX.md` |
| 精华长文（人读） | `DIGEST.md`（任务目录根，非运行期必需） |
| 路由测试题 | `test-prompts.json`（随件交付） |

补充件的作用是承载"四件套装不下、但运行期又需要"的内容。本技能的内容量（SKILL 24006 字节）与结构（§R 引文段已按簇分节）都不需要再拆一层，**多一个文件反而增加运行期要读的入口**。

## 2. 什么情况下应当回来补建 SUPPLEMENT

出现下列任一情形，本登记失效，必须补建 `SUPPLEMENT-<主题>.md`：

1. 主书之外**续补新书**，使 `## R 原文锚` 的簇超过 12 组、单文件不便查阅时 → 按簇拆 `SUPPLEMENT-引文池-<字母>.md`。
2. 需要附带**可执行脚本/词表**（如自建的判据检索器）超出四件套承载时。
3. 出现与主书口径**冲突**的第二来源，需要单列对照说明时。
