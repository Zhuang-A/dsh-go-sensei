# BOUNDARIES · go-detailed-explanation（边界与让位协议）

> 四件套之一（手册 v3.0 §185：SKILL / BOUNDARIES / INDEX / GLOSSARY）。
> 本文只讲**边界与交接**：谁该接、谁不该接、词面撞车时怎么判、让位时把什么交出去。
> 判据正文在 `SKILL.md`；术语与页锚在 `GLOSSARY.md`；引用关系在 `INDEX.md`。

## 1. 本技能承接什么（主诉判别句）

学生**要给一手棋一个说法**时归本技能。三个主诉特征，命中任一即接：

- **定性**：「这手怎么样」「为什么不好」「这算俗手吗」「这个形好不好」——要的是一句判断＋一条棋理。
- **改法**：「该怎么下」「改下哪里」「下次遇到这种形怎么办」——要的是**一条**主变＋一条可操作建议。
- **局部事实**：「这里连没连上」「这块棋安不安全」「几口气」——要的是棋形层面的解释（不是引擎数值）。

## 2. 不接什么（让位表）

| 学生要的 | 归谁 | 本技能让位时**交出**什么 |
|---|---|---|
| 胜率／目差／形势判断／AI 首选 | 围棋复盘工具族：`go_review_moves`、`go_position_context`、`go_engine_analyze` | 不说数字；可先讲棋理，再请学生调工具取数 |
| 变化图／要一张图 | `go_draw_diagram` | 本技能**不出图**；只给「第 N 手改下 X」的**文字**主变 |
| 死活／官子的精确结论 | 引擎复核（`go_engine_analyze`）后再回到本技能 | 只讲棋形事实（连没连、有没有眼），不给精确目数 |
| 整盘复盘报告 / 写回 SGF 注释 | 复盘流程工具：`go_write_review`、`go_export_report` | 本技能只负责**把一手棋讲清楚** |
| 与围棋无关的话题 | 不接 | 明说不在范围内 |

## 3. 同族词面重叠的**双向排除句**（手册 §17.7）

本技能的 description 与邻族存在两处词面重叠，两侧各写一句排除，缺一侧即视为**单侧声明**（不合格）：

- **「复盘」**：本技能 description **不含**「复盘」作触发词（原因：「复盘」同时是中文写作润色域与整盘复盘工具族的通用词，裸词会抢单；实测摘掉前跨域题 P6 被本技能抢单，摘掉后正确路由到 `qu-ai-wei`）。
  **反向句**：`qu-ai-wei`／`humanizer` 类写作润色技能**不接**棋理定性——「这手为什么是俗手」不是文字润色。
- **「改下」**：本技能保留「改下」作触发词（学生最常用的说法），但它同时贴近「改下某手会怎样」的变化图搜索。
  **反向句**：本技能对变化图请求**只给文字主变、不出图**；要图的学生请明确说「给我画一张」，届时归 `go_draw_diagram`。
  ⚠ 残留风险（已在 `gates-go-detailed-explanation.json` 登记为 residual）：触发词「改下」是裸词，词面拉力仍在，靠本节与 `SKILL.md` §B2 的让位条款在**语义层**兜住，机器层无法消除。

## 4. 情绪与医疗红线（判停优先于一切）

命中即**停止棋理讲解**，先给情绪支持并作专业交接：

- **情绪红线**：连输想放弃、觉得自己不适合下棋、不想下棋了、很绝望、想伤害自己、砸棋盘。
- **医疗/心理不适用域**：涉及诊断、用药、心理疾病治疗的问题，本技能**不接**，只作转介。

判停条款在 `SKILL.md` 的 `🔴 CHECKPOINT · 判停速查` 第 6 条；本文是它的边界侧声明。

## 5. 让位时的交接纪律

1. 让位要**说清楚让给谁、为什么**，不静默跳过。
2. 让位不等于拒答：先把能讲的棋理讲完，再说明数值/配图那一段要去哪取。
3. 绝不**冒充**另一个能力：没有引擎数据时不报数字，没有出图能力时不描述图片。
